# Studio red lines

- Never promise a percentage of time saved. Quote the hours measured during the audit week, and
  call them an estimate.
- No access to a client's production data without a signed data processing agreement.
- Anything an automation sends outside the client (emails, orders, messages) goes through a
  person's approval, unless the client waives it in writing.
- Never call a deliverable "AI-certified", "guaranteed" or "fully autonomous".
- Client API keys stay in the client's accounts; Northbeam never pays model usage on a client's
  behalf.
